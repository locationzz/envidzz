# about

        
> I build Minecraft plugins for Paper and Spigot on Java 21, targeting modern 1.21+ servers. My work leans toward the systems operators actually need: punishment suites that won't fight you, team frameworks with real roles and alliances, and utilities that do one thing correctly.

        
> Storage done right — YAML where it fits, SQL with migrations where it matters. Permission-aware commands with full tab completion. MiniMessage-formatted feedback. Admin tools that treat the operator as a user.

        
> Nether RTP scans for a solid block with two air above; LiteBanX resolves offline players via async Mojang lookup before the main thread ever blocks; TeamX persists a shared ender chest across restarts. When a plugin ships, it should feel like it came with the server.

SimpleRTP

            
Random-teleport that respects the terrain — and the player's patience.

            
    
              
  • /rtp opens a clickable dimension-picker GUI: Overworld / Nether / End; /rtp <dimension> teleports directly
    • 
              
  • Overworld lands only on true open-to-sky surfaces — never caves or overhangs
    • 
              
  • Nether/End scan vertically for a solid block with 2 air above
    • 
              
  • Avoids lava, water, fire, magma, cactus, campfires, powder snow, berries, wither rose, cobwebs, leaves, doors, fences, walls
    • 
              
  • Per-dimension radius, cooldown, and max attempts — all configurable
    • 
              
  • Enderman teleport sound on success
    • 
              
  • Admin: /rtpadmin enable|disable <dimension>, status, reload (alias /rtpa)
    •

TeamX

            
Teams with weight — roles, alliances, a shared chest, and a panel that actually works.

            
    
              
  • /team panel GUI; team home with warmup that cancels on move or damage
    • 
              
  • Shared ender chest persisted to disk across restarts (/team echest)
    • 
              
  • Roles: Owner / Officer / Member; owner announce and team chat (/tc)
    • 
              
  • Friendly-fire toggle; alliances (request/accept/break/deny) — allies can't damage each other
    • 
              
  • Tab list shows team name + color beside the player's name; rename, recolor, set description, disband
    • 
              
  • Admin: scan every team's shared chest for an item (/team admin echest scan mace); read-only snapshot of any team chest
    • 
              
  • YAML storage, one file per team; MiniMessage messages throughout
    •

LiteBanX (BanX)

            
A punishment suite that scales from a single /ban to a full moderation platform.

            
    
              
  • Punishments: ban, tempban, ipban, tempipban, mute, tempmute, warn, tempwarn, kick, note
    • 
              
  • Namespaced /banx <sub> with full tab completion; short forms (/ban, /mute…) work too
    • 
              
  • Order-insensitive parsing — duration and reason in any order
    • 
              
  • Offline player support via DB cache + async Mojang lookup
    • 
              
  • Reason system: shorthand reason ids + reusable templates (reasons.yml); warning points with auto-escalation thresholds
    • 
              
  • Alt detection via IP tracking, shared-account flags, and join alerts
    • 
              
  • Themed ban/mute/kick screens recolored from one theme block; on-screen broadcast titles
    • 
              
  • Custom cancellable PunishEvent / UnpunishEvent API
    • 
              
  • Storage: MySQL (HikariCP) or embedded SQLite with auto schema migration
    • 
              
  • PlaceholderAPI placeholders; optional webhook (HTTP POST JSON + X-BanX-Secret header)
    • 
              
  • Importers for AdvancedBan & LiteBans; exempt + override permissions
    • 
              
  • License: MIT
    •
