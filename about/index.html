# About

I build Minecraft plugins for Paper and Spigot on Java 21, targeting modern 1.21+ servers. My work leans toward the systems operators actually need: punishment suites that won't fight you, team frameworks with real roles and alliances, secure trading, and utilities that do one thing correctly.

Storage done right — YAML where it fits, SQL with migrations where it matters. Permission-aware commands with full tab completion. MiniMessage-formatted feedback. Admin tools that treat the operator as a user. When a plugin ships, it should feel like it came with the server.
